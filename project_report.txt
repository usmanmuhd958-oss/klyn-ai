1. EXECUTIVE STATE
------------------
KLYN is an active-development monorepo for an AI-native engineering platform.
The current root package uses pnpm 11.24.0, Node.js >=22, and Turbo for workspace
orchestration.

The repository contains current runtime packages alongside historical, generated,
experimental, and operational artifacts. Directory inventories are descriptive, not
architectural authority.

3. PRIMARY BACKEND SURFACE
--------------------------
Entry point: apps/backend/src/index.ts

The backend uses Express and exposes:

- GET /health
- GET /health/kernel
- GET /ready

Default local bind:
- HOST=127.0.0.1
- PORT=7860

Required configuration:
- JWT_SECRET (minimum 32 characters)
- ADMIN_PASSWORD (minimum 12 characters)

Optional provider/integration configuration includes:
- SUPABASE_URL
- SUPABASE_ANON_KEY
- OPENAI_API_KEY
- ANTHROPIC_API_KEY
- GEMINI_API_KEY

4. AI ENGINE SURFACE
--------------------
packages/ai-engine currently exports functionality for:

- provider adapters and provider registries;
- model routing, fallback, and circuit breaking;
- token telemetry and cost accounting;
- context budgeting and compaction;
- vector-memory and cross-agent knowledge interfaces;
- goal decomposition and task-graph planning;
- planner-to-runtime bridging;
- swarm coordination;
- spatial execution events;
- AI control-plane health and routing policy.
